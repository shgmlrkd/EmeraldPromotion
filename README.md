# 에메랄드 승급 과제

플레이어의 입력을 기반으로 전투 및 상호작용 시스템을 구현했습니다.

## 구현 내용

### 전투 시스템

- 마우스 좌클릭으로 공격 가능
- 공격 시 범위 내 적에게 데미지 적용
- 공격 애니메이션 재생 중 추가 입력 제한

### 상태 관리

- 플레이어 및 적 HP 시스템 구현
- HP가 0 이하일 경우 사망 후 다시 부활
- HP UI 실시간 갱신

### 상호작용 시스템

- 회복 아이템 획득 시 HP 회복
- 특정 구역 진입 시 지속 피해 적용

## 조작법

| 키 | 기능 |
| --- | --- |
| W A S D | 이동 |
| Shift | 달리기 |
| 좌클릭 | 공격 |
